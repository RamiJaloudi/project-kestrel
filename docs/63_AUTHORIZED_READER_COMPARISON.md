# Independently authorized reader comparison

[DEMO] 24 November 2026. The existing `frontend/src/DocumentReader.tsx` now also supports an embedded read-only pane. `CompareDocuments.tsx` supplies a two-to-four-pane dialog from Documents and Disclosures. Each pane retains its own source/derivative URL, reader state, text search, location selector, format renderer and 15-second authorization refresh. Comparison does not change source permissions or classifications.

The comparison picker uses bounded server-side candidate pages, stable created-at/ID ordering, allowlisted resource kinds and parameterized name/key filtering. It returns only the permitted page, an authorized last-row cursor and a permitted look-ahead flag. There is no global/denied count. Revoked or inaccessible cursors require a refresh. Preflight checks every pane against the selected matter and current source/derivative PDP; unavailable panes return no resource ID, title, private classification, location or denial reason. The actual pane GET rechecks access independently after preflight.

Existing source-reader and disclosure-reader responses add stable retained-unit citation anchors: version/artifact ID, Unicode offsets and applicable page, paragraph, table row, sheet/cell or CSV record coordinates. Historical source units remain unchanged. Page geometry is explicitly unavailable; sanitized artifacts expose sanitized coordinates only, without original IDs or private coordinate maps. Optional comparison offsets must identify an existing unit and exact bounded span.

Evidence text is the default in embedded panes; choose Document or Document + evidence per pane. Source pages and versions remain independent. No synchronized line alignment, semantic/legal redline, inferred financial equivalence or automatic risk reconciliation is claimed. Supported readers remain digital/scanned PDF, DOCX, bounded XLSX/CSV and UTF-8 text. Other Word/email/container/eDiscovery formats still require future safe converters.

Verification: 17 comparison/reader/disclosure/exact-cell tests passed; 3 comparison tests passed in isolated PostgreSQL schemas; TypeScript/Vite build passed. Tests prove authorized paging, unavailable cursors, exact version/derivative anchors, bank transcript access without original access, partial pane denial after clean-team revocation, and wall/admin denial. Visual verification is pending. No migration, legal approval or external release was required. Removing the comparison entry point reverts the UI increment while preserving existing reader URLs and retained records.

Swagger group: `/docs/readers`. The existing Start/Stop launchers continue to manage the shared API; there is no separate comparison service. Gate 4 DataTables work follows this baseline. Official React/core packages have been compatibility/license-checked and pinned, but installing them alone does not implement the table rebuild.
