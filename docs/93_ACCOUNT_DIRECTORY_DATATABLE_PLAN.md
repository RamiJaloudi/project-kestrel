## Implementation record

The shared wrapper now has a typed account-directory transport with no matter argument, a selection-free mode and correct column ordering without a Select-column offset. The account variant cannot receive source filters, generic exports, saved-query callbacks or selection actions. Other datasets keep their existing endpoints and matter request fields. AccountDirectoryDataTable supplies employer/active filters and metadata-only action cells.

AccountManagement opens a fresh revision-pinned record, preserves dirty text through unchanged background checks, requires explicit discard before switching a dirty account and clears protected state on stale authority. Its write body remains only name, employee ID and expected revision. Unknown write outcomes block resubmission. A bounded exact-ID directory read resolves the current revision, followed by a pinned detail read, before editing resumes; it never resends the uncertain update. The first implementation reused the old pin, which an independent review identified as unable to recover a committed-but-lost response. The corrected recovery and hydration marker were reviewed without further findings. Preview does not mount requesting children.

The dedicated backend reads only the eight published metadata fields, reauthenticates genuine firm Root authority and compares freshly prepared read results before responding. The old full-directory GET uses the same fresh guard. PATCH prepares its receipt before mutation, checks authority, writes under optimistic revision and target lock, then checks fresh authority/receipt before committing. Denied writes roll back both metadata and any allowed audit event. No legal matter guard is reused and no Root source override is added.

Tests first: 32 new cases failed before the feature existed. Four additional isolated legacy-route probes reproduced metadata being returned or committed after Root/session revocation; all four initially failed. After implementation, **36/36 new SQLite cases passed in 60.65 seconds**. The frontend TypeScript/Vite build passed with **86 modules**. The combined cross-database regression, final Swagger response DTO checks, local restart and browser acceptance are recorded below only when complete; this paragraph does not claim those pending checks passed.
