## Scope and limitations

- Q&A is a bounded local retrieval baseline: up to 200 permitted current source versions or released packages and eight matching passages. It is distinct from batch clause review. Keyword retrieval can miss relevant wording; it is not a production semantic index or proof of complete diligence.
- Legal SME historical impact/rerun approvals, a complete persistent SME Action Center, and tracker Excel import/export remain unfinished. Existing report Excel annex generation works. No silent historical reruns are enabled.
- External source access is limited to the explicit Halden grant exception. This is not a general client VDR. No new clean-team portal was created.
- Client-copy deletion does not delete firm retention records, protected backups or files already downloaded outside the application. A real retention/deletion schedule and legal-hold process still require counsel/security decisions.
- Full browser click/visual QA remains outstanding because desktop automation returns a Windows cursor-access error. TypeScript/Vite builds, real HTTPS API workflows and authorization tests were executed; that is not a claim of browser click verification.
- External WORM storage, portable key management, monitored off-machine backup retention, disaster recovery drills and public/Azure hardening remain deployment work. No public launch has occurred.
